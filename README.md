# Selenium Web Automation Project

## About the Project

This project is part of my Python learning journey. It focuses on web automation and web scraping using Selenium.

The project helps me practice automating browser actions, locating web elements, extracting information from web pages, and working with files in Python.

## Technologies Used

- **Python** — programming language
- **Selenium WebDriver** — browser automation
- **Google Chrome** — web browser
- **Git & GitHub** — version control

## Features

- Automating browser actions
- Opening and navigating web pages
- Finding web elements using Selenium
- Extracting text from web pages
- Saving extracted information to text files

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/TatevPiloyan/Selenium.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Selenium
   ```

3. Create a virtual environment:

   ```bash
   python -m venv venv
   ```

4. Activate the virtual environment on Windows:

   ```powershell
   .\venv\Scripts\Activate
   ```

5. Install Selenium:

   ```bash
   pip install selenium
   ```

## Usage

Run your Python Selenium script:

```bash
python main.py
```

Replace `main.py` with the name of your actual Python file.
